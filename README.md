# Замер скорости скачивания

Скрипт принимает HTTP- или HTTPS-адрес и делает 10 последовательных GET-запросов. Он выводит объем каждого ответа и длительность скачивания, а затем общий объем в байтах, среднее время в миллисекундах и скорость в Мбит/с.

## Запуск

Создайте виртуальное окружение и установите зависимости.

```bash
python3 -m venv .venv
source .venv/bin/activate
python speedtest.py "https://etolegko.ru/img/icons/megaphone_speaker.svg"
```

Среднее время— сумма длительностей запросов, деленная на 10. Скорость в Мбит/с — `общий объем в байтах × 8 / суммарное время в секундах / 1 000 000`.

Контрольный HTTPS-запуск на этом SVG дал 10 ответов по 1 596 байт, всего 15 960 байт. Среднее время составило 184,84 мс, скорость — 0,07 Мбит/с.

## Архитектура

| Модуль | Ответственность |
| --- | --- |
| [`speedtest.py`](speedtest.py) | Точка входа. Читает аргумент, вызывает проверку URL и замер, обрабатывает ошибки и передает итог для вывода. |

## Локальная проверка

### Позитивные сценарии

| № | Сценарий | Проверенный результат |
| --- | --- | --- |
| 1 | HTTP с длиной 10 байт | Прошел. Десять вызовов с исходным URL и таймаутом 30 с, по 10 байт каждый. |
| 2 | HTTPS с длиной 3 байта | Прошел. HTTPS-адрес принят и передан в каждый из десяти вызовов. |
| 3 | Пустое тело с `Content-Length: 0` | Прошел. Выведено 0 байт. |
| 4 | HTTP 204 без тела | Прошел. Выведено 0 байт. |
| 5 | Тело на 131 089 байт | Прошел. Сумма байтов точна при чтении нескольких порций. |
| 6 | Ответ без `Content-Length`, завершенный закрытием соединения | Прошел. Посчитано 5 байт до конца потока. |
| 7 | Ответ `chunked` из двух порций | Прошел. Посчитано 5 байт тела. |
| 8 | Два одинаковых `Content-Length` | Прошел. Посчитано 3 байта. |
| 9 | Последовательность запросов | Прошел. Каждый из десяти ответов закрыт до открытия следующего. |
| 10 | Показания таймера 1,00 и 1,25 с | Прошел. В журнал передана длительность 0,25 с. |

### Негативные сценарии

| № | Сценарий | Ожидаемый результат | Результат прогона |
| --- | --- | --- | --- |
| 1 | Неразбираемый URL `http://[` | Ошибка разбора, код выхода `1`. | Прошел. |
| 2 | URL со схемой `ftp` | Ошибка схемы, код `1`. | Прошел. |
| 3 | HTTPS-адрес без хоста | Ошибка хоста, код `1`. | Прошел. |
| 4 | HTTP 404 | Запись ошибки скачивания, код `1`. | Прошел. |
| 5 | Таймаут при чтении тела | Запись ошибки скачивания, код `1`. | Прошел. |
| 6 | Пришло 3 байта при `Content-Length: 4` | Ошибка неполного ответа, код `1`. | Прошел. |
| 7 | Ответ `chunked` без завершающей порции | Обработка `IncompleteRead`, код `1`. | Прошел. |
| 8 | Соединение прервалось на третьем запросе | Два успешных замера и одна ошибка, код `1`. | Прошел. Выполнено ровно три вызова. |
| 9 | `Content-Length: 3.5` | Отклонение некорректного заголовка, код `1`. | `expected failure`. Скрипт принимает ответ и завершается с кодом `0`. |
| 10 | `Content-Length: 3` и `Content-Length: 4` в одном ответе | Отклонение противоречивых заголовков, код `1`. | `expected failure`. Скрипт принимает ответ и завершается с кодом `0`. |


### Формулы и локальный HTTP-сервер

| Сценарий | Результат прогона |
| --- | --- |
| Подставной загрузчик с разными объемами и длительностями | Прошел. 7 500 000 байт, 1 000 мс в среднем, 6 Мбит/с. |
| Подставной загрузчик возвращает пустые тела | Прошел. Скорость 0 Мбит/с. |
| Суммарное время равно нулю | Прошел. Замер завершен ошибкой. |
| Сервер задерживает последний байт ответа | Прошел. Ровно 10 запросов без перекрытия, прочитано 655 530 байт. |
| URL со схемой `ftp` | Прошел. Код выхода `1`, сервер не получил запросов. |
| Сервер возвращает HTTP 404 | Прошел. Код `1`, ответ закрыт после первого запроса. |
| Сервер закрывает соединение до конца тела | Прошел. Код `1` после первого запроса. |
| Сервер оставляет тело незавершенным дольше таймаута | Прошел. Код `1` после первого запроса. |
